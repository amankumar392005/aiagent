# ⚙️ Backend Microservices Ecosystem

The backend is composed of an **API Gateway** and **5 domain-driven microservices** built on Node.js, Express 5.x, MongoDB, Redis, and LangChain/LangGraph.

---

## 🏗️ Backend Directory Overview

```
backend/
├── docker-compose.yml         # Local Redis service definition
├── package.json               # Backend workspace dependencies
├── gateway/                   # API Gateway Service (Port 6000)
├── shared/                    # Shared infrastructure modules (Redis client)
└── services/                  # Decoupled Domain Microservices
    ├── auth/                  # Authentication & Coin Ledger (Port 6001)
    ├── billing/               # Razorpay Payments (Port 6005)
    ├── interview/             # LangGraph AI Mock Interview Engine (Port 6003)
    ├── resume/                # ATS Resume Parser & Analyzer (Port 6002)
    └── roadmap/               # Career Roadmap Generator (Port 6004)
```

---

## 🔑 Shared Infrastructure (`shared/`)

- **`shared/redis/redis.js`**: Reusable `ioredis` singleton instance connecting to `REDIS_URL`. Standardizes key prefixes across services:
  - `session:<sessionId>` — Express session objects (7 days TTL)
  - `resume:<userId>` — Resume analysis payload cache
  - `userRoadmaps:<userId>` — Array of roadmaps generated by user (1 hour TTL)
  - `roadmap:<id>` — Single roadmap detailed view cache (1 hour TTL)

## 🚦 Port Assignment Matrix

| Component | Port | Description |
| :--- | :--- | :--- |
| **Redis** | `6379` | In-memory key-value session store & cache |
| **API Gateway** | `6000` | Entrypoint proxying requests to services |
| **Auth Service** | `6001` | Firebase Auth verification & User database |
| **Resume Service**| `6002` | File upload & Gemini ATS Resume engine |
| **Interview Service**| `6003` | LangGraph multi-turn interview state machine |
| **Roadmap Service**| `6004` | AI Career Roadmap & Resource Graph engine |
| **Billing Service**| `6005` | Razorpay order creation & payment verifier |

## 🚀 Running the Backend Services

Ensure Redis is running:
```bash
docker-compose up -d
```

Start all microservices independently or using a process manager:
```bash
# Gateway
cd gateway && npm run dev

# Services
cd services/auth && npm run dev
cd services/resume && npm run dev
cd services/interview && npm run dev
cd services/roadmap && npm run dev
cd services/billing && npm run dev
```

For complete setup details and environment variables, see [`../docs/SETUP_GUIDE.md`](../docs/SETUP_GUIDE.md).
